# Website

Закрытый рабочий сайт для сотрудников.

## Первый этап

- Регистрация только по автоматически сгенерированному приглашению.
- Каждый ключ уникален на уровне базы данных.
- Один ключ можно использовать только для регистрации одного аккаунта.
- Логины уникальны.
- Пароли хранятся в виде защищённых хешей.
- Подготовлена основа ролей доступа.
- FastAPI + SQLite на первом этапе, запуск в Docker.

## Запуск локально

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Проверка: `http://127.0.0.1:8000/health`

## Следующие этапы

1. Полноценная авторизация и сессии.
2. Первый аккаунт владельца и защита административной панели.
3. Интерфейс сайта: вход, регистрация по ключу, панель владельца.
4. Гибкие роли и права.
5. Разделы для рабочих данных после определения их структуры.
