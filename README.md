# Website-

Закрытая рабочая система: веб-сайт и полноценные мобильные приложения Android/iOS с общим backend.

## Что уже реализовано
- закрытая регистрация только по автоматически сгенерированному одноразовому ключу;
- один ключ может зарегистрировать только один аккаунт;
- уникальность ключей и логинов контролируется базой данных;
- роли: owner, admin, manager, worker;
- вход, сессии, выход и блокировка пользователей;
- самостоятельная смена логина и пароля;
- журнал важных действий;
- базовый модуль внесения рабочих данных и разграничение просмотра по ролям;
- отдельный веб-интерфейс и Flutter-приложение без WebView.

## Структура
- `app/` — backend API и база данных;
- `web/` — браузерная версия;
- `mobile/` — исходный код настоящего Android/iOS приложения;
- `.github/workflows/` — автоматические проверки и сборки.

## Запуск
```bash
docker build -t website- .
docker run -p 8000:8000 -v $(pwd)/data:/app/data website-
```

После запуска сайт доступен на порту 8000.

## Важно перед эксплуатацией
Перед публичным запуском необходимо настроить HTTPS, резервное копирование, секреты окружения и постоянную базу данных. SQLite подходит для начальной версии и небольшого числа пользователей; для крупной одновременной нагрузки рекомендуется PostgreSQL.

## План
Следующий этап — настраиваемые формы рабочих данных, полноценное управление пользователями в интерфейсе, уведомления и подготовка закрытого распространения мобильных приложений.
